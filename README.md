# MedBook API

API для керування розкладом лікарів та записом пацієнтів на прийом. Побудовано з фокусом на строгі інженерні стандарти, якість коду та автоматизацію процесів (згідно із завданням лабораторної роботи).

## Технологічний стек

- **Runtime:** Node.js
- **Framework:** Fastify
- **Database:** PostgreSQL + Drizzle ORM
- **Quality Assurance:** ESLint, Prettier, Husky, lint-staged

## Запуск та розробка

Проєкт використовує `Makefile` для управління життєвим циклом та автоматизації рутини.

### Доступні команди:

- `make setup` — встановлення залежностей та ініціалізація git-hooks (Husky).
- `make lint` — перевірка коду лінтером (статичний аналіз).
- `make format` — форматування коду за допомогою Prettier.
- `make build` — перевірка типів та збірка TypeScript.
- `make test-smoke` — запуск базових smoke-тестів (перевірка валідності архітектури).

## Структура проєкту

- `/src` — вихідний код застосунку (розбитий на модулі: `users`, `appointments`, `schedules`).
- `/standards` — внутрішні стандарти якості проєкту (наприклад, Definition of Done).
- `/docs/adr` — Architectural Decision Records (документація ключових архітектурних рішень).
- `/ai` — збережені логи промптів та взаємодії з ШІ (для аудиту рішень).
